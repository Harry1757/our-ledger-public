## 비밀값·공개 파일

| 검사 | 결과 |
| --- | --- |
| 원본 비공개 저장소 Git 이력, 34개 커밋 | Gitleaks 8.30.1 검사. 경고 1건은 문서의 `api:` 배포 이미지 태그를 비밀키로 오인한 것으로 확인 |

| 추가 패턴·파일 목록 검토 | 운영 호스트·개발팀 ID·개인 경로 제거 확인. DB·키 파일·환경변수·서명 산출물·작업 로그 제외 |
| 공개 화면 6장·표지 1장 | 새 합성 데이터로 촬영/제작하고 각 이미지의 표시 내용 확인 |
| 원본 작업 보존 | 변경 파일·미추적 소스와 Git 이력을 로컬 백업. 원본 diff 보존 확인 |

원본 이력은 공개 저장소로 복사하지 않았습니다. 자동 검사는 모든 형태의 개인정보나 취약점을 보장하지 않습니다.

Python의 제외 31개는 명시적인 실클라우드 환경이 필요한 Firestore 통합 검사입니다. 이번 작업에서는 운영 DB에 접속하지 않았습니다. 메모리 저장소 대역을 쓰는 Firestore 검사는 로컬 테스트에 포함됩니다.

의존성 검사는 실행 시점에 알려진 취약점 목록을 확인한 결과입니다. 모든 코드나 향후 취약점의 안전성을 보장하는 판정은 아닙니다.

## 이번에 보완한 보안 동작

- PC 연결로 발급한 세션에 서버 기준 30일 만료를 적용했습니다.
- 연결 해제는 서버 토큰을 폐기한 뒤 쿠키를 지웁니다. 서버 폐기 실패 시 성공으로 표시하지 않습니다.
- PC 세션으로 새 PC 연결 코드를 발급하거나 해당 세션을 부모로 재연결할 수 없게 했습니다.
- 명시적인 loopback 개발 환경을 제외하면 HTTPS·Secure 쿠키를 사용합니다.
- 개발 기본값은 로컬 서버이며 외부 배포에는 관리자 환경변수로 HTTPS API를 지정해야 합니다.

만료·경계 시각·폐기·재시도·저장 실패 시 보존·네이티브 세션 호환·출처·HTTPS 설정을 회귀 검사했습니다.

## 확인하지 않은 부분

- 실기기 두 대의 최신 빌드 다운로드·동기화·실제 금융사 알림 전달
- 실제 Cloud Run·Firestore에 대한 보안 수정 배포와 운영 회귀 검사
- 계정 복구·탈퇴·모든 기기 원격 로그아웃 UI
- 외부 침투 테스트와 클라우드 IAM 권한 감사

기존 운영 서비스와 공개 소스의 배포 상태는 다릅니다. 이번 보안 수정은 공개본에만 적용했으며, 운영 반영은 별도 검증·배포 작업이 필요합니다.
